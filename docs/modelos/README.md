# Modelos: proposta, contrato e passo a passo da implantação

`proposta-contrato-implantacao.html` é o exemplo aprovado do que o cliente recebe
no fluxo de venda (spec local `2026-11-05-venda-ate-pagamento-design.md`), com uma
clínica fictícia e os valores que `content/pricing.toml` calcula para o escopo.
Abra no navegador; as três abas são `#proposta`, `#contrato` e `#implantacao`.

- **Proposta** (incremento 3): gerada quando a equipe aprova o orçamento, com a
  arte da Converge e o link para o passo a passo da implantação.
- **Contrato** (incremento 4): o modelo de 04/11/2026, texto integral. Corpo e
  Anexo II fixos; partes, Anexo I e Anexo III preenchidos a partir da proposta
  aceita. Ainda é minuta: falta a revisão final do advogado.
- **Passo a passo da implantação**: as etapas das cláusulas 3.1 a 3.4 e o que o
  cliente prepara (requisitos do FAQ).

O que está destacado em amarelo é preenchido pelo sistema. Em aberto: a data das
cláusulas-padrão da ANPD (Anexo I.5).
