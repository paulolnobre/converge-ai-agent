# Inbox no painel — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** uma aba Inbox no `/painel` onde a equipe vê as conversas em andamento, assume e responde ao cliente pelo painel. O grupo do Telegram só recebe avisos de uma linha com o botão "Abrir no painel", e cada contato tem canal e origem.

**Architecture:**
- **Dados:** uma migração nova (`0005_inbox.sql`) e um repositório novo (`core/repositories/inbox.py`) com as leituras da Inbox e as reservas atômicas: o aviso de conversa nova e o aviso no privado.
- **Serviço:** `core/services/inbox.py`, com assumir, devolver, responder, avisos e a porta única de envio por canal. `core/services/handoff.py` deixa de repassar pelo Telegram e passa a usar esse serviço.
- **Painel:** o `panel.py` ganha as rotas `/api/inbox*` e `/api/contacts/{id}/origin`. A tela é um script novo, `inbox.js`, no mesmo padrão do `automacoes.js` (só `textContent`).

**Tech Stack:** Python 3.12, FastAPI, psycopg 3 (async), Postgres, Telegram Bot API, JS puro no painel, pytest, Playwright (E2E fora do repositório).

**Spec:** `docs/superpowers/specs/2026-09-29-inbox-design.md`

## Review Focus

1. **Mensagem que chega fora de ordem na tela.** Uma resposta do bot gravada numa transação longa pode receber um id menor que a resposta da equipe gravada antes. Se a conversa pedisse só `id > último`, essa mensagem nunca apareceria. Por isso `messages(after)` devolve também tudo dos últimos 10 minutos, e a tela junta pelo id (teste de SQL real na Task 1, mais a lógica no `inbox.js`).
2. **Duas pessoas clicando "Assumir" ao mesmo tempo.** A primeira fica com a conversa, e a segunda recebe 409 "mudou de mãos", nunca uma troca silenciosa (`claim_by_user` com o dono esperado; testes nas Tasks 2 e 4).
3. **Botão com endereço que o Telegram recusa** (`PUBLIC_BASE_URL` vazio ou local). O aviso sai sem botão em vez de não sair (`notify_team` tenta de novo sem teclado; teste na Task 2).
4. **Login expirado ao tocar no botão.** A pessoa volta para `#inbox/<id>` depois de entrar, e nenhum outro fragmento é aceito (Task 5, com teste estático e E2E).
5. **Mensagem do cliente contada duas vezes enquanto espera uma pessoa.** No estado "aguardando", o handoff não grava mais a mensagem, porque o fluxo normal já grava. Isso corrige a duplicata que existe hoje (teste na Task 3).

Crie `infra/migrations/0005_inbox.sql`:

```sql
-- The Inbox: the team answering from /painel instead of from Telegram, the
-- channel a contact talks through and how they found Converge.
-- Safe to repeat, like every migration (cli/migrate.py applies it once).

-- contacts.source already holds the channel (init.sql: "the channel the
-- person first arrived through"). It gains the channels this service knows.
DO $$
BEGIN
  IF NOT EXISTS (SELECT 1 FROM pg_constraint WHERE conname = 'contacts_source_channel') THEN
    ALTER TABLE contacts ADD CONSTRAINT contacts_source_channel
      CHECK (source IN ('telegram', 'whatsapp', 'instagram', 'messenger', 'email'));
  END IF;
END $$;

-- How the person found Converge: the first one known wins, the team may
-- change it in the panel (origin_set_by says who did).
ALTER TABLE contacts
  ADD COLUMN IF NOT EXISTS origin VARCHAR(30)
    CHECK (origin IN ('anuncio_instagram', 'anuncio_facebook', 'site', 'google',
                      'indicacao', 'outro')),
  ADD COLUMN IF NOT EXISTS origin_detail VARCHAR(160),
  ADD COLUMN IF NOT EXISTS origin_set_by INTEGER REFERENCES panel_users(id) ON DELETE SET NULL,
  -- When the team group was last told this conversation started: one notice
  -- per conversation, a conversation being 24h without the person writing.
  ADD COLUMN IF NOT EXISTS conversation_noticed_at TIMESTAMPTZ;

-- Who holds a conversation from the panel (claimed_by_id stays for the claims
-- made the old way, by replying in Telegram), and when they were last told
-- the customer wrote.
ALTER TABLE handoff_sessions
  ADD COLUMN IF NOT EXISTS claimed_by_user_id INTEGER REFERENCES panel_users(id) ON DELETE SET NULL,
  ADD COLUMN IF NOT EXISTS last_ping_at TIMESTAMPTZ;

-- Who in the team wrote a message sent from the panel.
ALTER TABLE sessions
  ADD COLUMN IF NOT EXISTS author_user_id INTEGER REFERENCES panel_users(id) ON DELETE SET NULL;
```

                        expected_owner: int | None) -> bool:
    """Take a session for someone signed in to /painel — only while it is
    still with whoever the panel showed (`expected_owner`: None for nobody,
    or for a claim made the old way, in Telegram). Two people clicking
    "Assumir" at once: the first gets it, the second is told it changed hands."""

            "UPDATE handoff_sessions SET status = 'claimed', claimed_by_user_id = %s, "
            "claimed_by_name = %s, claimed_by_id = NULL, "

            "WHERE id = %s AND status IN ('open', 'claimed') "
            "  AND claimed_by_user_id IS NOT DISTINCT FROM %s",
            (user_id, name, session_id, expected_owner),
        )
        return cur.rowcount > 0

Crie `core/repositories/inbox.py`:

```python
"""The Inbox tab: every conversation in progress, and who holds it.

Reads join what the conversation already records — sessions for the words,
handoff_sessions for who holds it — so the Inbox shows the facts the bot acts
on. The two claims are single UPDATEs: two messages arriving together, or two
workers, get one notice between them, never two.
"""
from __future__ import annotations

from psycopg.rows import dict_row

FILTERS = ("waiting", "mine", "bot", "all")

_STATE = (
    "CASE h.status WHEN 'claimed' THEN 'claimed' WHEN 'open' THEN 'waiting' "
    "ELSE 'bot' END"
)

_LIST = f"""
    SELECT c.id AS contact_id, c.name, c.source AS channel, c.origin,
           {_STATE} AS state,
           h.claimed_by_name AS owner_name, h.claimed_by_user_id AS owner_user_id,
           COALESCE(h.claimed_by_user_id = %(user_id)s, FALSE) AS mine,
           last.role AS last_role, left(last.message, 120) AS last_message,
           last.created_at AS last_at
      FROM contacts c
      LEFT JOIN handoff_sessions h
             ON h.contact_id = c.id AND h.status IN ('open', 'claimed')
      LEFT JOIN LATERAL (
          SELECT role, message, created_at FROM sessions s
           WHERE s.contact_id = c.id
           ORDER BY s.created_at DESC, s.id DESC LIMIT 1
      ) last ON TRUE
     WHERE NOT EXISTS (SELECT 1 FROM staff st WHERE st.chat_id = c.chat_id)
       AND (h.id IS NOT NULL OR last.created_at > NOW() - INTERVAL '7 days')
"""

# Fixed fragments only — nothing from a request is ever pasted into SQL.
_WHERE = {
    "waiting": " AND h.status = 'open'",
    "mine": " AND h.status = 'claimed' AND h.claimed_by_user_id = %(user_id)s",
    "bot": " AND h.id IS NULL",
    "all": "",
}


async def list_conversations(conn, *, user_id: int, state: str = "all",
                             channel: str | None = None, limit: int = 200) -> list[dict]:
    sql = _LIST + _WHERE[state]
    if channel:
        sql += " AND c.source = %(channel)s"
    sql += " ORDER BY last.created_at DESC NULLS LAST, c.id DESC LIMIT %(limit)s"
    async with conn.cursor(row_factory=dict_row) as cur:
        await cur.execute(sql, {"user_id": user_id, "channel": channel, "limit": limit})
        return list(await cur.fetchall())


async def count_waiting(conn) -> int:
    """For the menu: conversations where someone asked for a person and
    nobody has taken it yet."""
    async with conn.cursor() as cur:
        await cur.execute(
            "SELECT count(*) FROM handoff_sessions h JOIN contacts c ON c.id = h.contact_id "
            "WHERE h.status = 'open' "
            "  AND NOT EXISTS (SELECT 1 FROM staff st WHERE st.chat_id = c.chat_id)"
        )
        row = await cur.fetchone()
    return int(row[0]) if row else 0


async def conversation(conn, contact_id: int, user_id: int) -> dict | None:
    async with conn.cursor(row_factory=dict_row) as cur:
        await cur.execute(
            f"SELECT c.id AS contact_id, c.chat_id, c.name, c.phone, c.email, c.stage, "
            f"       c.source AS channel, c.origin, c.origin_detail, h.id AS session_id, "
            f"       {_STATE} AS state, h.claimed_by_name AS owner_name, "
            f"       h.claimed_by_user_id AS owner_user_id, "
            f"       COALESCE(h.claimed_by_user_id = %(user_id)s, FALSE) AS mine "
            f"  FROM contacts c "
            f"  LEFT JOIN handoff_sessions h "
            f"         ON h.contact_id = c.id AND h.status IN ('open', 'claimed') "
            f" WHERE c.id = %(contact_id)s",
            {"contact_id": contact_id, "user_id": user_id},
        )
        return await cur.fetchone()


_MESSAGE = (
    "SELECT s.id, s.role, s.message, s.intent, s.created_at, u.name AS author "
    "FROM sessions s LEFT JOIN panel_users u ON u.id = s.author_user_id "
)


async def messages(conn, contact_id: int, after_id: int | None = None,
                   limit: int = 200) -> list[dict]:
    """The conversation, oldest first.

    With after_id, what came after it — and everything from the last ten
    minutes too. Ids are handed out when a row is written, not when its
    transaction commits: a bot reply written inside a slow turn can land
    with a smaller id than a team reply that committed first, and asking
    only for "id > the last one seen" would skip it for good. The panel
    merges by id, so the overlap costs nothing.
    """
    async with conn.cursor(row_factory=dict_row) as cur:
        if after_id is None:
            await cur.execute(
                f"SELECT * FROM ({_MESSAGE} WHERE s.contact_id = %s "
                "ORDER BY s.id DESC LIMIT %s) m ORDER BY id",
                (contact_id, limit),
            )
        else:
            await cur.execute(
                f"{_MESSAGE} WHERE s.contact_id = %s "
                "  AND (s.id > %s OR s.created_at > NOW() - INTERVAL '10 minutes') "
                "ORDER BY s.id LIMIT %s",
                (contact_id, after_id, limit),
            )
        return list(await cur.fetchall())


async def claim_conversation_notice(conn, contact_id: int) -> bool:
    """True once per conversation: the person has not written in 24h (or
    ever), was not announced in 24h, and is not someone from the team. Call it
    before this message is recorded. Two messages at once: the second waits
    on the row lock, then finds the notice already taken."""
    async with conn.cursor() as cur:
        await cur.execute(
            "UPDATE contacts c SET conversation_noticed_at = clock_timestamp() "
            "WHERE c.id = %s "
            "  AND (c.conversation_noticed_at IS NULL "
            "       OR c.conversation_noticed_at < NOW() - INTERVAL '24 hours') "
            "  AND NOT EXISTS (SELECT 1 FROM sessions s WHERE s.contact_id = c.id "
            "                   AND s.role = 'user' "
            "                   AND s.created_at > NOW() - INTERVAL '24 hours') "
            "  AND NOT EXISTS (SELECT 1 FROM staff st WHERE st.chat_id = c.chat_id) "
            "RETURNING c.id",
            (contact_id,),
        )
        return await cur.fetchone() is not None


async def claim_owner_ping(conn, session_id: int, minutes: int) -> bool:
    """True when the person holding this conversation may be told again that
    the customer wrote — at most once every `minutes`."""
    async with conn.cursor() as cur:
        await cur.execute(
            "UPDATE handoff_sessions SET last_ping_at = clock_timestamp() "
            "WHERE id = %s AND (last_ping_at IS NULL "
            "  OR last_ping_at < clock_timestamp() - make_interval(mins => %s)) "
            "RETURNING id",
            (session_id, minutes),
        )
        return await cur.fetchone() is not None


async def owner_chat_id(conn, user_id: int) -> str | None:
    """The Telegram chat of a /painel account: the staff row with the same
    e-mail (content/staff.json). None when there is none to write to."""
    async with conn.cursor() as cur:
        await cur.execute(
            "SELECT st.chat_id FROM panel_users u "
            "JOIN staff st ON lower(st.email) = lower(u.email) "
            "WHERE u.id = %s AND st.active AND st.chat_id IS NOT NULL",
            (user_id,),
        )
        row = await cur.fetchone()
    return row[0] if row else None


async def set_origin(conn, contact_id: int, origin: str | None, detail: str | None,
                     user_id: int) -> bool:
    async with conn.cursor() as cur:
        await cur.execute(
            "UPDATE contacts SET origin = %s, origin_detail = %s, origin_set_by = %s, "
            "updated_at = NOW() WHERE id = %s",
            (origin, detail, user_id, contact_id),
        )
        return cur.rowcount > 0


async def set_origin_if_empty(conn, contact_id: int, origin: str) -> bool:
    """The first origin known wins: a later link never overwrites it."""
    async with conn.cursor() as cur:
        await cur.execute(
            "UPDATE contacts SET origin = %s, updated_at = NOW() "
            "WHERE id = %s AND origin IS NULL",
            (origin, contact_id),
        )
        return cur.rowcount > 0
```

The team group only hears one-line notices, each with a button that opens the
conversation in the panel; the conversation itself is read and answered
there. One conversation, one owner: only the person who took it can send, and
while they hold it the bot stays quiet (core/services/handoff.py). Every
reply goes out through send(), the one place a second channel plugs into.

from __future__ import annotations

import logging

from core import content
from core.config import settings
from core.integrations import telegram
from core.models import Contact, HandoffSession
from core.repositories import contacts as contacts_repo
from core.repositories import handoffs as handoffs_repo
from core.repositories import inbox as inbox_repo

logger = logging.getLogger(__name__)

MAX_REPLY = 4000             # Telegram's own limit is 4096
OWNER_PING_MINUTES = 5
CHANNEL_LABELS = {
    "telegram": "Telegram", "whatsapp": "WhatsApp", "instagram": "Instagram",
    "messenger": "Facebook", "email": "E-mail",
}
ORIGINS = ("anuncio_instagram", "anuncio_facebook", "site", "google", "indicacao", "outro")
# What a t.me/<bot>?start=<origin> link may claim. Anything else is ignored.
_START_ORIGINS = ("site", "google", "indicacao", "anuncio_instagram", "anuncio_facebook")


class InboxError(Exception):
    """A refusal the panel shows as it is; `status` is the HTTP status."""

    def __init__(self, status: int, detail: str):
        super().__init__(detail)
        self.status = status
        self.detail = detail


def channel_label(channel: str | None) -> str:
    return CHANNEL_LABELS.get(channel or "", channel or "—")


def first_name(name: str | None) -> str:
    parts = (name or "").split()
    return parts[0] if parts else "Equipe"


def origin_from_start(body: str) -> str | None:
    """"/start site" → "site"."""
    parts = body.strip().split()
    if len(parts) != 2 or parts[0].split("@")[0].lower() != "/start":
        return None
    value = parts[1].lower()
    return value if value in _START_ORIGINS else None


def _team() -> str:
    return settings.team_chat_id.strip()


def open_keyboard(contact_id: int) -> dict | None:
    base = (settings.public_base_url or "").rstrip("/")
    if not base:
        return None
    return telegram.link_keyboard(
        content.text("inbox.open_button"), f"{base}/painel#inbox/{contact_id}"
    )


async def notify_team(text: str, contact_id: int | None) -> bool:
    """One line in the team group, with the button when there is an address.
    A button Telegram refuses (a local address, say) must not cost the notice."""
    if not _team():
        return False
    keyboard = open_keyboard(contact_id) if contact_id is not None else None
    if await telegram.post_message(_team(), text, reply_markup=keyboard) is not None:
        return True
    if keyboard is None:
        return False
    return await telegram.post_message(_team(), text) is not None


async def send(channel: str, chat_id: str, text: str) -> bool:
    """A reply to the customer, on the channel they wrote from."""
    if channel == "telegram":
        return await telegram.send_message(chat_id, text, parse_mode=None)
    raise InboxError(501, "Canal ainda não conectado.")


async def notify_new_conversation(conn, contact: Contact) -> bool:
    """The first message ever, or the first in 24h: one line to the team."""
    if contact.id is None or not _team():
        return False
    if not await inbox_repo.claim_conversation_notice(conn, contact.id):
        return False
    return await notify_team(content.render(
        "inbox.new_conversation", nome=contact.name or "Sem nome",
        canal=channel_label(contact.channel),
    ), contact.id)


async def _contact(conn, contact_id: int) -> Contact:
    contact = await contacts_repo.get_by_id(conn, contact_id)
    if contact is None or contact.id is None or not contact.chat_id:
        raise InboxError(404, "Conversa não encontrada.")
    return contact


async def claim(conn, contact_id: int, user: dict) -> None:
    """Take the conversation — one someone asked a person for, one the bot is
    having, or one someone else holds. The group hears who has it now."""
    contact = await _contact(conn, contact_id)
    assert contact.chat_id is not None
    session = await handoffs_repo.active_session(conn, contact.chat_id)
    if session is not None and session.claimed_by_user_id == user["user_id"]:
        return
    if session is None:
        session = await handoffs_repo.open_session(
            conn, contact_id=contact.id, chat_id=contact.chat_id, team_chat_id=_team(),
            reason="painel",
        )
    if session.id is None:
        raise InboxError(409, "Não foi possível assumir agora. Tente de novo.")
    previous = session.claimed_by_name if session.status == "claimed" else None
    me = first_name(user["name"])
    if not await handoffs_repo.claim_by_user(
        conn, session.id, user["user_id"], me, session.claimed_by_user_id
    ):
        raise InboxError(409, "Esta conversa acabou de mudar de mãos. Atualize para ver com quem está.")
    nome = contact.name or "Sem nome"
    text = (content.render("inbox.reassigned", nome=nome, atendente=me, anterior=previous)
            if previous else content.render("inbox.claimed", nome=nome, atendente=me))
    await notify_team(text, contact.id)


async def reply(conn, contact_id: int, user: dict, text: str) -> None:
    """Send what the owner wrote. Recorded only once the channel took it: the
    history must never show a message the customer did not get."""
    body = text.strip()
    if not body:
        raise InboxError(422, "Escreva a mensagem.")
    if len(body) > MAX_REPLY:
        raise InboxError(422, f"A mensagem pode ter até {MAX_REPLY} caracteres.")
    contact = await _contact(conn, contact_id)
    assert contact.chat_id is not None
    session = await handoffs_repo.active_session(conn, contact.chat_id)
    if session is None or session.id is None or session.status != "claimed":
        raise InboxError(409, "Assuma a conversa para responder.")
    if session.claimed_by_user_id != user["user_id"]:
        raise InboxError(409, f"{session.claimed_by_name or 'Outra pessoa'} assumiu esta conversa.")
    outgoing = content.render("handoff.relay", atendente=first_name(user["name"]), mensagem=body)
    if not await send(contact.channel, contact.chat_id, outgoing):
        raise InboxError(502, content.render("inbox.send_failed", canal=channel_label(contact.channel)))
    await contacts_repo.record_message(
        conn, contact.id, contact.chat_id, "assistant", outgoing, "relay",
        author_user_id=user["user_id"],
    )
    await handoffs_repo.touch(conn, session.id)


async def release(conn, contact_id: int, user: dict) -> None:
    """Give the conversation back to the bot, and say so to both sides."""
    contact = await _contact(conn, contact_id)
    assert contact.chat_id is not None
    session = await handoffs_repo.active_session(conn, contact.chat_id)
    if session is None or session.id is None or not await handoffs_repo.close(conn, session.id):
        raise InboxError(409, "Esta conversa já está com o assistente.")
    text = content.text("handoff.back_to_bot")
    try:
        delivered = await send(contact.channel, contact.chat_id, text)
    except InboxError:
        delivered = False
    if delivered:
        await contacts_repo.record_message(conn, contact.id, contact.chat_id, "assistant", text, "handoff")
    await notify_team(content.render(
        "inbox.released", nome=contact.name or "Sem nome", atendente=first_name(user["name"])
    ), contact.id)


async def ping_owner(conn, session: HandoffSession, contact: Contact) -> None:
    """Tell whoever holds the conversation that the customer wrote — never
    what they wrote, and at most once every OWNER_PING_MINUTES."""
    if session.id is None or session.claimed_by_user_id is None:
        return
    chat_id = await inbox_repo.owner_chat_id(conn, session.claimed_by_user_id)
    if not chat_id:
        logger.info("Panel user %s has no Telegram chat; no private notice",
                    session.claimed_by_user_id)
        return
    if not await inbox_repo.claim_owner_ping(conn, session.id, OWNER_PING_MINUTES):
        return
    await telegram.post_message(
        chat_id, content.render("inbox.owner_ping", nome=contact.name or "Sem nome"),
        reply_markup=open_keyboard(contact.id) if contact.id is not None else None,
    )

A session with no message on either side for HANDOFF_TIMEOUT_MINUTES closes

None of this is read by a model: a tap, a command or a click already says

from typing import Literal

from core import content
from core.config import settings
from core.integrations import telegram
from core.models import Contact
from core.repositories import contacts as contacts_repo
from core.repositories import handoffs as handoffs_repo

def configured() -> bool:

async def start(conn, contact: Contact, chat_id, reason: str) -> bool:
    """Open a session and tell the team — or nothing new if a person already
    holds it, since the customer only ever has one live request to the team.
    Asked again while it waits, the team is told again."""
    if not configured():
        logger.warning("Handoff requested but TEAM_CHAT_ID is not set.")
        return False
    session = await handoffs_repo.open_session(
        conn, contact_id=contact.id, chat_id=chat_id, team_chat_id=_team(), reason=reason,
    )
    if session.id is None:
        return False
    if session.status != "open":
        return True  # a person already holds it
    motivo = content.text(f"inbox.reason_{reason}") if reason in ("pedido", "botao") else reason
    return await inbox.notify_team(content.render(
        "inbox.needs_person", nome=contact.name or "Sem nome",
        canal=inbox.channel_label(contact.channel), motivo=motivo,
    ), contact.id)


async def handle_customer_message(conn, contact: Contact, chat_id, body: str
                                  ) -> Literal["claimed", "waiting"] | None:
    """Where a message goes when the team was called in.

    "claimed": a person holds the conversation. The message is recorded for
    the panel and that person hears, privately, that the customer wrote; the
    caller must not run triage on it. "waiting": nobody has taken it yet, and
    the bot answers as usual (the caller records the message). None: no one
    was called in.
    """
    session = await handoffs_repo.active_session(conn, chat_id)
    if session is None or session.id is None:
        return None

    if body.strip().lower() == "/bot":
        await handoffs_repo.close(conn, session.id)
        text = content.text("handoff.back_to_bot")
        await telegram.send_message(chat_id, text)
        if configured():
            await telegram.post_message(
                _team(), content.render("handoff.closed_notice", nome=contact.name or "o cliente")
            )
        if contact.id is not None:
            await contacts_repo.record_message(conn, contact.id, chat_id, "assistant", text, "handoff")
        return "claimed"

    await handoffs_repo.touch(conn, session.id)

/* Inbox — every conversation in progress, and answering from the panel.
   Names and messages come from strangers, so everything is written with
   textContent. The list refreshes every 10s and an open conversation every
   4s, only while this tab is on screen. */
(function () {
  "use strict";

  var FILTERS = [["waiting", "Esperando pessoa"], ["mine", "Comigo"], ["bot", "Com o bot"], ["all", "Todas"]];
  var CHANNELS = { telegram: "Telegram", whatsapp: "WhatsApp", instagram: "Instagram", messenger: "Facebook", email: "E-mail" };
  var STAGES = { novo: "Novo lead", respondido: "Bot respondeu", agendado: "Conversa agendada",
                 proposta: "Proposta enviada", fechado: "Fechado", perdido: "Perdido" };
  var LIST_MS = 10000, THREAD_MS = 4000, COUNT_MS = 30000;
  var TOUCH = window.matchMedia("(pointer: coarse)").matches;

  var filter = "all", channelFilter = "", openId = null, current = null;
  var seen = {};            // message id -> message, for the open conversation
  var originDirty = false;

  function $(id) { return document.getElementById(id); }
  function el(tag, cls, text) {
    var node = document.createElement(tag);
    if (cls) node.className = cls;
    if (text != null) node.textContent = text;
    return node;
  }
  function button(label, cls, onClick) {
    var b = el("button", cls, label); b.type = "button"; b.addEventListener("click", onClick); return b;
  }

  function api(path, options) {
    var opts = options || {};
    return fetch("/painel/api" + path, {
      method: opts.method || "GET",
      credentials: "same-origin",
      headers: opts.body ? { "Content-Type": "application/json" } : {},
      body: opts.body ? JSON.stringify(opts.body) : undefined
    }).then(function (r) {
      if (r.status === 401) {
        location.replace("/painel/entrar" + (/^#inbox\/\d+$/.test(location.hash) ? location.hash : ""));
        throw new Error("Sessão expirada.");
      }
      return r.json().catch(function () { return {}; }).then(function (data) {
        if (!r.ok) {
          var detail = data && data.detail;
          throw new Error(Array.isArray(detail) ? "Confira a mensagem." : (detail || "Erro " + r.status));
        }
        return data;
      });
    });
  }

  function when(value) {
    if (!value) return "";
    var d = new Date(value), today = new Date();
    var time = d.toLocaleTimeString("pt-BR", { hour: "2-digit", minute: "2-digit" });
    if (d.toDateString() === today.toDateString()) return time;
    return d.toLocaleDateString("pt-BR", { day: "2-digit", month: "2-digit" }) + " " + time;
  }
  function stateText(c) {
    if (c.mine) return "Com você";
    if (c.state === "claimed") return "Com " + (c.owner_name || "alguém");
    return c.state === "waiting" ? "Esperando pessoa" : "Bot";
  }
  function stateClass(c) { return "inbox-state " + c.state + (c.mine ? " mine" : ""); }
  function isActive() { return $("view-inbox").classList.contains("active"); }

  // ── The list ───────────────────────────────────────────────────────────
  function renderFilters() {
    var box = $("inbox-filter"); box.textContent = "";
    FILTERS.forEach(function (f) {
      var chip = button(f[1], "agenda-chip " + (filter === f[0] ? "on" : "off"), function () {
        filter = f[0]; renderFilters(); loadList();
      });
      box.appendChild(chip);
    });
  }

  function setCount(n) { var c = $("count-inbox"); c.textContent = n; c.hidden = !n; }

  function loadList() {
    var query = "?filter=" + filter + (channelFilter ? "&channel=" + encodeURIComponent(channelFilter) : "");
    return api("/inbox" + query).then(function (data) {
      renderList(data.conversations || []);
      setCount(data.waiting_total || 0);
    }).catch(function (err) {
      var list = $("inbox-list"); list.textContent = "";
      list.appendChild(el("p", "empty-line", "Não foi possível carregar as conversas: " + err.message));
    });
  }

  function renderList(rows) {
    var list = $("inbox-list"); list.textContent = "";
    if (!rows.length) {
      list.appendChild(el("p", "empty-line", filter === "waiting"
        ? "Ninguém esperando uma pessoa agora."
        : "Nenhuma conversa nos últimos 7 dias."));
      return;
    }
    rows.forEach(function (c) {
      var row = button("", "inbox-row" + (c.contact_id === openId ? " active" : ""), function () {
        openConversation(c.contact_id);
      });
      var top = el("div", "inbox-row-top");
      top.appendChild(el("span", "inbox-name", c.name || "Sem nome"));
      top.appendChild(el("span", "inbox-when", when(c.last_at)));
      var mid = el("div", "inbox-row-mid");
      mid.appendChild(el("span", stateClass(c), stateText(c)));
      mid.appendChild(el("span", "inbox-channel", CHANNELS[c.channel] || c.channel || ""));
      row.appendChild(top); row.appendChild(mid);
      if (c.last_message) {
        row.appendChild(el("div", "inbox-preview", (c.last_role === "user" ? "" : "↪ ") + c.last_message));
      }
      list.appendChild(row);
    });
  }

  // ── One conversation ───────────────────────────────────────────────────
  function openConversation(id) {
    openId = id; current = null; seen = {}; originDirty = false;
    history.replaceState(null, "", "#inbox/" + id);
    $("inbox").classList.add("thread-open");
    $("inbox-empty").hidden = true; $("inbox-thread").hidden = false;
    $("thread-messages").textContent = ""; $("thread-actions").textContent = "";
    $("thread-name").textContent = "Carregando…"; $("thread-sub").textContent = "";
    $("thread-origin-msg").textContent = ""; note("", false);
    Array.prototype.forEach.call(document.querySelectorAll(".inbox-row"), function (r) { r.classList.remove("active"); });
    loadThread(true);
  }

  function closeConversation() {
    openId = null; current = null;
    history.replaceState(null, "", "#inbox");
    $("inbox").classList.remove("thread-open");
    $("inbox-thread").hidden = true; $("inbox-empty").hidden = false;
    loadList();
  }

  function lastSeenId() {
    var ids = Object.keys(seen).map(Number);
    return ids.length ? Math.max.apply(null, ids) : null;
  }

  function loadThread(full) {
    if (openId == null) return;
    var id = openId, after = full ? null : lastSeenId();
    api("/inbox/" + id + (after != null ? "?after=" + after : "")).then(function (data) {
      if (id === openId) apply(data, full);
    }).catch(function (err) { if (id === openId) note(err.message, true); });
  }

  // The server may send a message again (the overlap of the last ten minutes)
  // or one older than the last seen: merge by id, render in id order.
  function apply(data, full) {
    if (full) seen = {};
    current = data.contact;
    renderHead();
    var fresh = false;
    (data.messages || []).forEach(function (m) { if (!seen[m.id]) { seen[m.id] = m; fresh = true; } });
    if (fresh || full) renderMessages(full);
  }

  function renderHead() {
    var c = current;
    $("thread-name").textContent = c.name || "Sem nome";
    $("thread-sub").textContent = [CHANNELS[c.channel] || c.channel, c.phone, c.email, STAGES[c.stage] || c.stage]
      .filter(Boolean).join(" · ");
    var actions = $("thread-actions"); actions.textContent = "";
    actions.appendChild(el("span", stateClass(c), stateText(c)));
    if (!c.mine) {
      actions.appendChild(button(c.state === "claimed" ? "Assumir no lugar" : "Assumir", "btn btn-accent",
        function () { act("claim"); }));
    }
    if (c.state !== "bot") actions.appendChild(button("Devolver ao bot", "btn", function () { act("release"); }));

    var origin = $("thread-origin"), detail = $("thread-origin-detail");
    if (!originDirty && document.activeElement !== origin && document.activeElement !== detail) {
      origin.value = c.origin || ""; detail.value = c.origin_detail || "";
    }

    var canWrite = !!c.mine;
    $("thread-text").disabled = !canWrite;
    $("thread-send").disabled = !canWrite;
    var lock = $("thread-lock");
    lock.hidden = canWrite;
    lock.textContent = c.state === "claimed"
      ? "Com " + (c.owner_name || "outra pessoa") + ". Assuma para responder."
      : "Assuma a conversa para responder.";
  }

  function renderMessages(scrollToEnd) {
    var box = $("thread-messages");
    var atEnd = box.scrollHeight - box.scrollTop - box.clientHeight < 40;
    box.textContent = "";
    var ids = Object.keys(seen).map(Number).sort(function (a, b) { return a - b; });
    if (!ids.length) box.appendChild(el("p", "empty-line", "Sem mensagens."));
    ids.forEach(function (id) {
      var m = seen[id];
      var team = !!m.author || m.intent === "relay";
      var who = m.role === "user" ? ((current && current.name) || "Cliente")
        : (m.author || (team ? "Equipe" : "Assistente"));
      var wrap = el("div", "msg " + (m.role === "user" ? "user" : "assistant") + (team ? " team" : ""));
      wrap.appendChild(el("div", "msg-body", m.message));
      wrap.appendChild(el("div", "msg-when", who + " · " + when(m.created_at)));
      box.appendChild(wrap);
    });
    if (scrollToEnd || atEnd) box.scrollTop = box.scrollHeight;
  }

  function note(text, isError) {
    var n = $("thread-msg"); n.className = "auto-msg" + (isError ? " err" : ""); n.textContent = text;
  }

  function act(kind) {
    var id = openId; note("", false);
    api("/inbox/" + id + "/" + kind, { method: "POST" }).then(function (data) {
      if (id !== openId) return;
      apply(data, true); loadList();
      if (kind === "claim" && !TOUCH) $("thread-text").focus();
    }).catch(function (err) { note(err.message, true); loadThread(true); });
  }

  function sendReply() {
    var box = $("thread-text"), text = box.value.trim();
    if (!text || openId == null || $("thread-send").disabled) return;
    var id = openId;
    $("thread-send").disabled = true; note("Enviando…", false);
    api("/inbox/" + id + "/reply", { method: "POST", body: { text: text } }).then(function (data) {
      if (id !== openId) return;
      box.value = ""; note("", false);
      apply(data, true); loadList();
    }).catch(function (err) {
      note(err.message, true);
      if (current && current.mine) $("thread-send").disabled = false;
    });
  }

  function saveOrigin() {
    if (openId == null) return;
    var id = openId, msg = $("thread-origin-msg");
    msg.className = "auto-msg"; msg.textContent = "Salvando…";
    api("/contacts/" + id + "/origin", { method: "PATCH", body: {
      origin: $("thread-origin").value || null,
      detail: $("thread-origin-detail").value.trim() || null
    } }).then(function (data) {
      originDirty = false;
      if (id !== openId) return;
      apply(data, true);
      msg.className = "auto-msg ok"; msg.textContent = "Salvo.";
    }).catch(function (err) { msg.className = "auto-msg err"; msg.textContent = err.message; });
  }

  // ── Wiring ─────────────────────────────────────────────────────────────
  $("thread-send").addEventListener("click", sendReply);
  $("thread-text").addEventListener("keydown", function (e) {
    // Enter sends on a computer; on a phone Enter is a new line and the button sends.
    if (!TOUCH && e.key === "Enter" && !e.shiftKey) { e.preventDefault(); sendReply(); }
  });
  $("thread-back").addEventListener("click", closeConversation);
  $("thread-origin").addEventListener("change", function () { originDirty = true; });
  $("thread-origin-detail").addEventListener("input", function () { originDirty = true; });
  $("thread-origin-save").addEventListener("click", saveOrigin);
  $("inbox-channel").addEventListener("change", function (e) { channelFilter = e.target.value; loadList(); });

  var nav = document.querySelector('.nav-item[data-view="inbox"]');
  function onOpen() {
    // painel.js has just set the address to #inbox; keep the open conversation in it.
    if (openId != null) history.replaceState(null, "", "#inbox/" + openId);
    loadList();
  }
  nav.addEventListener("click", onOpen);
  nav.addEventListener("keydown", function (e) { if (e.key === "Enter") onOpen(); });

  renderFilters();
  var linked = location.hash.match(/^#inbox\/(\d+)$/);
  if (location.hash.split("/")[0] === "#inbox") {
    loadList();
    if (linked) openConversation(Number(linked[1]));
  } else {
    api("/inbox?filter=waiting").then(function (data) { setCount(data.waiting_total || 0); }).catch(function () {});
  }

  setInterval(function () { if (!document.hidden && isActive()) loadList(); }, LIST_MS);
  setInterval(function () { if (!document.hidden && isActive() && openId != null) loadThread(false); }, THREAD_MS);
  setInterval(function () {
    if (document.hidden || isActive()) return;
    api("/inbox?filter=waiting").then(function (data) { setCount(data.waiting_total || 0); }).catch(function () {});
  }, COUNT_MS);
})();
